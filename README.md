# College Saver

College Saver is a web-based platform designed to help students find and purchase essential supplies for various college courses, including Engineering, IT, and Medicine. The site features a user-friendly interface, product listings, shopping cart, and checkout functionality.

## Features
- Browse supplies by category (Engineering, IT, Medicine)
- Add items to cart and checkout
- User authentication (login/signup)
- Contact and About pages
- Responsive design

## Folder Structure
- `index.html`, `home.html`, etc.: Main site pages
- `cart.js`, `checkout.js`, `script.js`, etc.: JavaScript for interactivity
- `style.css`, `cart.css`, `product.css`: Stylesheets
- `img/`: Images and product icons
- `img/Engineering/`, `img/IT/`, `img/Medicine/`: Category-specific images

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/JAE20/College-Saver.git
   ```
2. Open `index.html` in your browser to start using the site.
